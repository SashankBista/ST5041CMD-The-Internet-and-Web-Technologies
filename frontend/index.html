    return Correct()

how a round runs.
From the first challenge to the final report, in three stages.

    

      
Before the event
Set it up
Create the event, add challenges and categories, set start and end times, and invite teams.

      
During the event
Let teams play
Players solve, submit flags and climb while you post announcements and watch the activity.

      
After the event
Review the round
Look through the activity log, see which skills were hardest and share the results.
