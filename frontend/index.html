from rootline import challenge, award, log

@challenge(
    id="sql-login-bypass",
    category="web",
    points=300,
    rate_limit="10/min",
)
def check(submission):
    digest = sha256(submission.flag)

    if not compare(digest, STORED_HASH):
        log("wrong_flag", team=submission.team)
        return Wrong()

    award(submission.team, points=300)
    return Correct()

how a round runs.
From the first challenge to the final report, in three stages.

    

      
Before the event
Set it up
Create the event, add challenges and categories, set start and end times, and invite teams.

stuff your professor needs to see.
No fancy animations here, just the facts. The platform is built to be attacked, and then fixed.

    

      
Password hashing
Passwords stored with bcrypt. Never plain text, never reversible.

      
CSRF protection
A token on every state-changing form, verified on the server.

      
Rate limiting
Login and flag submission are capped per user and per address.

      
Role-based access
Admin and player roles enforced on every route, not just hidden in the menu.

      
Input validation
Parameterized queries and escaped output stop injection and XSS.

      
Audit trail
Every sensitive action is recorded with who, what and when.
